# تسليم متابعة العرض (v129)

## نقطة البدء

- النسخة الجاهزة المستقلة هي: `versions/v129-simple-explain-layer/`.
- افتح العرض من: `index.html`.
- هذه النسخة مبنية من (v127)، لكن كل الملفات والرسومات المطلوبة موجودة داخل مجلد (v129) نفسه.
- لا تعدّل (v129) بعد نشرها. لأي تعديل جديد انسخها إلى مجلد جديد مثل `versions/v130-.../`، ثم عدّل النسخة الجديدة فقط.
- لا تغيّر رابط `current`؛ هو يشير إلى نسخة تاريخية أخرى، وتركناه كما هو عمدًا.

## ما الذي أُنجز

1. أضيفت طبقة شرح مبسّط لكل الشرائح الـ276 في التسلسل الرئيسي.
   - افتحها بزر (E) أو زر (Plain words) في الشريط السفلي.
   - تعمل في وضع (Still) ووضع (Interactive).
   - تعرض: الفكرة ببساطة، مثال أو الخطوة التالية عند وجوده، كلمات أساسية، ومكان الشريحة في القصة.

2. أضيف الشرح المبسّط كذلك إلى 59 صفحة تفصيلية داخل 17 لوحة شرح اختيارية.
   - في الوضع التفاعلي افتح لوحة التفاصيل، ثم استخدم زر (Plain words) أو زر (E).
   - زر (Esc) يغلق طبقة الشرح ويعيد إلى نفس صفحة التفاصيل؛ ثم (Esc) مرة أخرى يعود للشريحة الرئيسية.

3. لم تتغير أرقام البحث، الجداول، الفترات، النتائج السلبية، أو التحفظات العلمية.
   - طبقة الشرح تعيد استعمال نص الشريحة أو الملاحظات أو الرسوم الموجودة.
   - ثماني صفحات تفاصيل مبنية على معادلات أو رسومات فقط أضيف لها تلخيص قصير يدوي يعيد صياغة القاعدة الموجودة بالفعل، من دون حساب نتيجة جديدة.

4. ظلت أوضاع البداية كما هي:
   - (Still): كل العناصر تظهر فورًا، من دون أنشطة أو تشغيل ذاتي.
   - (Interactive): الرسوم تبني نفسها سريعًا تلقائيًا، ولا ينتقل العرض بين الشرائح من تلقاء نفسه.

## خريطة الملفات المهمة

| الملف | دوره |
|---|---|
| `index.html` | الشرائح والنصوص ولوحات التفاصيل |
| `script.js` | التنقل، الوضعان، الشرح المبسّط، المخططات والرسوم البيانية |
| `styles.css` | شكل الشرائح واللوحات وطبقة الشرح |
| `modes.css` | الفروق بين الوضع الثابت والتفاعلي |
| `assets/data/results.js` | البيانات الرقمية المصدرية للرسوم البيانية |
| `build_result_bars.py` | إنشاء صور أعمدة النتائج والتحقق من الأرقام |
| `check_modes_browser.js` | اختبار متصفح شامل للوضعين وطبقات الشرح |
| `PLAIN_GUIDE_AUDIT.md` | حدود طبقة الشرح وما تغطيه |
| `RESULT_BAR_AUDIT.md` | مصدر أعمدة النتائج وحدود التقريب |
| `DIAGRAM_AUDIT.md` و`VISUAL_AUDIT.md` و`INTERACTION_AUDIT.md` | توثيق الرسوم والتفاعل |

## أماكن التعديل الدقيقة

- منطق الشرح الرئيسي: ابحث في `script.js` عن (makeGuide) و(renderGuide) و(openExplain).
- تلخيص الصفحات التفصيلية التي لا تبدأ بنص بسيط: الكائن (DETAIL_SIMPLE) داخل `script.js`.
- شرح صفحات التفاصيل: ابحث عن (openDetailGuide) و(xguide) داخل `script.js`.
- زر الشرح في الشريط: ابحث عن (guide-btn) داخل `script.js` و`styles.css`.
- شكل النافذة: ابحث عن (.explain) و(.ex-box) في `styles.css`.
- لا تعدّل القيم في الرسوم أو نتائج الورقتين من نص العرض يدويًا؛ ابدأ من `assets/data/results.js` وراجع `RESULT_BAR_AUDIT.md`.

## اختبارات إلزامية بعد أي تعديل

نفّذ الأوامر من داخل مجلد (v130) الجديد أو داخل (v129) عند المراجعة فقط:

```sh
node --check script.js
node check_diagrams.js
node check_beginner_visuals.js
node check_interactivity.js
python3 build_result_bars.py --check
node check_modes_browser.js
```

الاختبار الأخير يحتاج (Chrome) محليًا. النجاح المتوقع يشمل 276 دليل شرح للشرائح و59 دليل شرح لصفحات التفاصيل، مع اختبار الرجوع الصحيح بواسطة (Esc).

## ما لم يُنجز بعد

- هذه النسخة ليست إعادة كتابة لكل جملة مرئية في العرض؛ إنها طبقة شرح مبسّط فوق المحتوى الكامل.
- لا يوجد مسار مختصر منفصل لمدة 20 دقيقة. إذا طُلب ذلك، أنشئ نسخة جديدة تختار شرائح من التسلسل الحالي ولا تحذف أو تغيّر (v129).
- قبل إضافة رسومات أو أرقام جديدة، راجع مصدرها في ملفات التدقيق أو في الورقتين. لا تخمّن نتائج أو نسب أو فترات ثقة.

## قواعد الاستمرار

- احتفظ بكل النسخ التاريخية كما هي، وأنشئ مجلد نسخة جديد لكل تغيير.
- لا تشغّل استدلال الكاشف أو التتبع أو إعادة ضبط المعاملات بغرض تعديل العرض؛ هذا عرض توثيقي لنتائج موجودة.
- بعد تعديل الشيفرة شغّل `graphify update .` من جذر المشروع لتحديث خريطة الملفات.
- لا تنقل أو تحذف ملفات العرض القديمة.
